Cara Mengaktifkan Pengiriman Otomatis (1 Menit):
  1. Buka spreadsheet target melalui tombol Buka Sheet di atas.
  2. Klik menu Ekstensi > Apps Script.
  3. Paste script dari file google-apps-script.js yang telah disediakan.
  4. Klik Deploy > Deployment baru > Pilih jenis Aplikasi Web.
  5. Set "Yang memiliki akses" ke "Siapa saja" (Anyone), lalu deploy.
  6. Copy URL Aplikasi Web dan tempelkan pada kolom di atas, lalu klik Simpan.
